# Matsu RallyCon v0.8.59 — PDFなしシンプル版

## 開発方針
ユーザー確認により、画面方向の選択機能は採用せず、従来どおり端末・ブラウザの画面回転動作に任せる。

## 変更内容
- v0.8.56のPDFなし起動構成を基準として採用。
- 起動時に内蔵A5コマ図PDFを自動表示しない。
- PDF未読み込み時は中央エリアを空き表示領域として使用し、PDF読み込み案内を表示。
- 必要なときにLOAD PDFから手動で読み込む。
- 既存のPDF読み込みモード（自動判定／コマ練モード／PDF表示モード）を維持。
- v0.8.58で追加したDIRボタン、画面方向選択UI、画面方向ロック処理は含めない。
- GPS位置取得・距離積算・距離補正、PDF解析、TOTAL/RB同期、NEXT/BACK、AUTO NEXT、START/STOP、SmartRemote関連の処理は変更しない。
- バージョン表記をv0.8.59に更新。

## 検証
- JavaScript構文検査、HTML ID重複検査、主要UI要素の存在確認、ZIP整合性およびZIP内外ファイル一致を実施。
- 実機でのGPS走行、セッション復元、SmartRemote、各PDFモードの追加実機試験は未実施。

## 注意
本版は画面方向を強制しない。画面の縦横は端末・ブラウザの従来の動作に従う。
