# Matsu RallyCon v0.8.60 — PDF未読込時ルートなし

## 変更内容
- 起動時の `ROUTE` を空配列にし、PDF未読込時に既定ルートを有効化しない。
- PDF未読込時の RB / TARGET / NEXT は `--` 表示。
- PDF未読込時に NEXT / BACK を操作してもルート参照エラーにならないようガード。
- PDF読み込み後の既存ルート選択・PDF解析処理は変更しない。
- 既存の A4_ROUTE 定義は、識別済みの KOMAREN Classic 2026 PDF を読み込んだ場合に使う既存データとして保持。起動時には割り当てない。

## 変更していない範囲
- GPS取得・バックグラウンド復帰・距離計算
- PDF解析ロジック、読み込みモード
- SmartRemote、画面レイアウト、画面回転制御

## 検証
- JavaScript構文検査、HTML ID重複、ZIP整合性を確認。
- 実機でのPDF読み込み後の動作は未検証。RT11で確認が必要。
