# Matsu RallyCon v0.8.58 — 画面方向選択版

## 基準
- v0.8.55のソースを基準にしたPDFなし起動版 v0.8.56を土台として使用。
- v0.8.57で追加したアプリ全体のRALLYCON/PDF VIEW二重モードは採用しない。

## 変更内容
- 起動時に内蔵されていたA5 PDFは引き続き搭載しない。
- 初回起動時に「縦画面／横画面」を選択。
- 選択した方向をlocalStorageに保存し、次回起動時に再適用を要求。
- ヘッダーのDIRボタンから画面方向を再選択可能。
- 既存のPDF読み込み時の「自動判定／コマ練モード／PDF表示モード」は維持。
- 既存のPDF表示・GPS・距離計算・TOTAL/RB・NEXT/BACK・AUTO NEXT・SmartRemoteの処理は今回の変更対象外。

## 検証
- JavaScript構文検査、HTML ID重複検査、PDF読み込みモードUIの存在確認、ZIP整合性検査を実施。
- RT11での画面方向ロック、PDF読み込み、GPS走行、SmartRemote、セッション復元は未実機確認。

## 注意
- 画面方向の強制はブラウザ／ホーム画面アプリの対応状況に依存。ロックできない場合は端末の向きに従って既存CSSレイアウトが切り替わる。
- 本版では新しいPDF VIEW専用アプリモードを追加していない。
