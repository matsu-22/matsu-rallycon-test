Matsu RallyCon v0.8.57 — モード選択・画面方向設定

基準：ユーザー提供 v0.8.56 PDFなし起動版。v0.8.55の元ファイルも別途保管。

変更内容
- 起動時にアプリ全体の使用モードを選択（初回のみ）。
- RALLYCON MODEでは縦画面／横画面を選択し、選択内容を保存。
- PDF VIEW MODEを追加。PDF読み込み時は必ず距離/RB解析なしのPDFVIEWとして読み込む。
- PDF VIEW MODEではGPS・CAP・STARTおよび左右のラリー情報パネルを隠し、閲覧用レイアウトにする。
- PDF VIEW MODEではRALLYCONのセッション保存を行わず、既存のラリーセッションを上書きしない。
- 次回起動時は前回のアプリモードと画面方向を復元。MODEボタンから変更可能。
- PDFを読み込んだ状態でアプリ全体のモードを変更する場合は、確認後に再読み込みしてPDFを選び直す。
- 既存のPDF読み込みモード（AUTO/KOMA/PDFVIEW）はRALLYCON MODE内で従来どおり利用可能。

重要な制限・未実装
- 画面方向の固定はScreen Orientation API対応ブラウザに対して要求する。ブラウザ／PWAの制約で拒否された場合は端末の向きに追従する。実機確認が必要。
- PDF VIEW MODEのPDFファイル・閲覧ページ位置の再起動後復元は今回未実装。PDFは再起動後に再選択が必要。
- RALLYCONの走行セッション復元は、同一PDF識別を安全に行う仕組みが未実装のため、今回新たに有効化していない。
- GPS計測の再開、実機の画面回転、PDF閲覧の保存／復元は実機テスト未実施。

検証
- JavaScript構文検査、変更差分、ZIP整合性を別途確認。
- 実機走行・GPS・SmartRemoteの検証は未実施。
